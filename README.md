# Flexible Workspace Digital Maturity Assessment

A self-contained web diagnostic instrument calibrated to evaluate enterprise digital capability within the flexible workspace industry (WeWork operational model)[cite: 1, 2].

The tool evaluates organizational performance across five domain-specific capability dimensions, calculates leveled maturity scores, dynamically generates an interactive radar visualization, and diagnoses strategic capability gaps with targeted interventions[cite: 1, 2].

## Framework Architecture & Capability Dimensions

The diagnostic measures operational maturity across five independent dimensions, each evaluated using strictly observable, non-evaluative organizational criteria[cite: 1, 2]:

| # | Dimension | Diagnostic Focus |
|---|---|---|
| 1 | **Workspace & Portfolio Data**[cite: 1, 2] | Sensor telemetry, zone utilization, and real-time integration with master lease liabilities and margin-at-risk ledgers[cite: 1, 2]. |
| 2 | **Member Digital Experience**[cite: 1, 2] | Self-service capabilities covering mobile desk/room booking, identity federation (SSO), and automated support resolution[cite: 1, 2]. |
| 3 | **Workspace Operations Automation**[cite: 1, 2] | Dynamic foot-traffic custodial dispatching, zero-touch network/SCIM provisioning, and occupancy-responsive HVAC/BMS controls[cite: 2]. |
| 4 | **AI-Enabled Portfolio Intelligence**[cite: 1, 2] | Real-time algorithmic dynamic pricing, badge-telemetry early churn signals, and macro absorption site selection models[cite: 2]. |
| 5 | **Digital Operating Model**[cite: 1, 2] | Cross-functional product squad alignment, staff workflow enablement systems, and audited venture-style tech capital governance[cite: 2]. |

## Technical Implementation

- **Architecture:** Zero-dependency, single-file application (`index.html`) executable directly in modern browsers without backend or local server requirements[cite: 2].
- **Data Engine:** Vanilla JavaScript data structures defining all dimensions, diagnostic questions, explicit integer weights (1–5), and deterministic tie-breaking logic[cite: 2].
- **Data Visualization:** Client-side radar chart rendered using Chart.js via CDN (`jsdelivr`), dynamically scaling axes and series points to computed dimension averages[cite: 2].
- **State Management:** In-memory form validation preventing premature submissions, responsive accordion stage navigation, and zero persistent storage/cookies[cite: 2].
